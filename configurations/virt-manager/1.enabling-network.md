To install virtio drivers do the following

Then create a new disk of type CDROM, and choose the virtio iso

Open the VM then install the driver by running the following in cmd as admin

```sh
pnputil /add-driver "E:\NetKVM\w10\amd64\netkvm.inf" /install
```

Reboot

Then add this to firewalld

```sh
sudo firewall-cmd --add-masquerade --zone=libvirt --permanent
sudo firewall-cmd --reload
```
